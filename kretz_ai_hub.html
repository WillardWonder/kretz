Start here.

Seven habits from the training. If you remember nothing else, remember these.

A person signs offNo external, financial, safety or technical AI work goes out without human review.
Protect the dataConfidential Kretz or landowner information stays out of unapproved tools.
AI is not a calculatorAsk for formulas and sources, not finished numbers. Verify anything that matters.
Sound like KretzOutgoing messages use the Kretz DNA voice and keep every fact intact.
Pass means doneWhen every checklist item passes, it is approved. Suggestions never block.
The builder owns itUnless a sign-off owner is named, whoever built the tool answers for it.
Report without blameErrors and near-misses get reported so the process improves.

Your goals, milestones and Tool Cards live in this browser. Save them as one program file to back up, share with the team, or move to another computer.

How the files fit together.
The program file holds goals, milestones and every Tool Card. The AI Tool Register and the Session 3 tools read the same Tool Cards, so a card saved anywhere on this site shows up everywhere on it. An offline copy of this page keeps its own data, so use the program file to move work between copies.

This is one suggested way to track progress. The CSV export from the register moves the cards into Excel, SharePoint or any system Kretz chooses.
