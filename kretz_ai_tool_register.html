How the files work.

Plain files, so the register keeps working without internet, without accounts, and without this website.

Card file (.json)One tool. Download it from the Session 3 Tool Card builder or from a card here. Email it, store it in a shared folder, load it into any copy of this register.
Register file (.json)Every card in one file. Export it to back up or share the whole register; load it on another computer to pick up where you left off.
Register CSVOpens in Excel or imports into SharePoint, Teams or another list tool. Edit it in Excel and load it back here if you want.
Stored on this deviceCards you save stay in this browser only. Clearing browser data erases them, so export the register after changes.
Offline useDownload this page and open it from your computer. It needs no internet. An offline copy keeps its own saved cards, so use files to move cards between copies.
Cleared for useEvery required field is filled in, including a named sign-off owner, or the builder accepts ownership. Missing any one means not cleared.
Review datesCards with a review date in the past are flagged overdue; within 30 days, due soon. The checklist owner updates the date after each review.
Make it yoursAdd custom fields, or move to another system entirely. What matters is that every tool has an owner, a checklist and a review date.
